# Image Generation Prompts for Theory Sections
## Comic-Style Illustrations for Robot Framework Training

---

## Visual Style Guidelines

**Art Style**:
- Modern comic book / graphic novel aesthetic
- Clean line art with bold outlines
- Limited color palette: Teal (#5AB3B3), dark grays (#1A1A1A, #2A3F3F), accent red (#DC3545)
- Sci-fi tech aesthetic with retro-futuristic elements
- Dramatic lighting with teal/cyan glows
- Panel-style composition where applicable

**Character Design**:
- **PROTO-7**: Smaller, sleeker robot with rounded design, curious/eager expression, teal accent lights, novice appearance
- **MENTOR-9**: Larger, more angular robot with authoritative presence, experienced battle-worn look, multiple sensor arrays, calm/patient demeanor

**Setting**:
- Interior of crashed spaceship "Starlight Explorer"
- Damaged control panels with holographic displays
- Teal/cyan emergency lighting
- Visible hull damage, exposed wiring
- Planet Syntax-IV visible through cracked viewports (barren, purple-tinted landscape)

## Alternative Visual Concepts (Optional)

### Concept A: Panel Sequences (Comic Strip Style)

Instead of single images, create 3-4 panel sequences for each exercise showing progression:

**Example for Exercise 1.1.1**:
- Panel 1: PROTO-7 confused, looking at blank terminal
- Panel 2: MENTOR-9 explaining, showing first Log command
- Panel 3: Code appearing line by line
- Panel 4: Success - all 5 messages displayed sequentially

**Dimensions**: 1920x600 (horizontal strip)

### Concept B: Code-as-Environment

Visualize code keywords as physical objects in the ship:

- "Log" keywords are communication panels
- "*** Test Cases ***" is a doorway/gateway
- Variables are storage containers
- Keywords section is a toolbox/workshop area

**Style**: More environmental/metaphorical, less literal code display

### Concept C: Minimalist Icons

Simple, iconic representations for theory concepts:

- Sequential execution: Arrow cascade
- Log levels: Traffic light (green/yellow/red)
- Dual channels: Split pipe/fork
- Syntax flexibility: Shape-shifting symbol
- File structure: Layered documents

**Dimensions**: 800x800 (square icons)
**Style**: Flat design, high contrast, teal/gray palette

## Technical Specifications for All Images

### File Format
- **Primary**: PNG with transparency support
- **Fallback**: WEBP for better compression
- **Naming Convention**: `ex-{chapter}-{section}-{exercise}-{concept}.png`

### Color Palette (Hex Codes)
```
Primary Teal:    #5AB3B3
Dark Background: #1A1A1A
Card Background: #2A3F3F
Accent Red:      #DC3545
Success Green:   #28A745
Warning Yellow:  #FFC107
Text Light:      #FFFFFF
Text Muted:      #B8C5C5
```

### Dimensions & Optimization
- **Target Resolution**: 1920x1080 (16:9 widescreen)
- **Minimum Resolution**: 1280x720
- **File Size Target**: 150-250KB per image
- **Optimization**: Use PNG compression tools (pngquant, TinyPNG)
- **Retina Support**: Consider @2x versions at 3840x2160 for high-DPI displays

### Accessibility
- **Alt Text**: Provided in metadata for each image
- **Contrast Ratio**: Minimum 4.5:1 for all text elements within images
- **Fallback**: Ensure theory text remains readable if images fail to load

## Image Generation Tools Recommended

1. **Midjourney** (v6 or later)
   - Best for comic book style
   - Excellent with sci-fi aesthetics
   - Use `--ar 16:9` for aspect ratio
   - Use `--style raw` for more control

2. **DALL-E 3**
   - Good text integration in images
   - Reliable for specific scenes
   - Use detailed prompts

3. **Stable Diffusion XL** (with ControlNet)
   - Open source, full control
   - Good for consistent character designs
   - Use LoRA models for comic book style

4. **Manual Illustration** (if budget allows)
   - Commission comic book artist
   - Provides most control and consistency
   - Can maintain character designs across all images

## Notes for Image Generation

1. **Consistency is Key**: Use same character designs across all images
2. **Readable Code**: Ensure any code shown in holograms is large enough to read
3. **Color Psychology**: Use green for success, yellow for warnings, red for errors
4. **Action Over Static**: Show robots interacting with code, not just standing
5. **Environmental Storytelling**: Background details reinforce the "stranded ship" narrative
6. **Educational Clarity**: Visual metaphors should enhance understanding, not confuse
7. **Test on Mobile**: Images should be understandable even at small sizes
